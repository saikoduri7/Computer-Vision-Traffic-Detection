# Pretrained models

The `.pt` file contains learned neural-network weights, not your input footage
or crossing counts; downloading it does not train the model on your video.

The default model is `yolo11n.pt`, downloaded by Ultralytics on first use.
No custom model was trained for this project. The Colab notebook caches weights
in Google Drive. Weights are excluded from Git.

See [YOLO11](https://docs.ultralytics.com/models/yolo11/) and
[Ultralytics licensing](https://www.ultralytics.com/license).
