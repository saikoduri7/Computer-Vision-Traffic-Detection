# Example artifacts

To add a real run, use the notebook's Results Export cell and upload its small
artifacts here; keep full annotated videos in Drive or the README demo attachment.

`sample_counts.json` and `sample_crossings.csv` describe a deliberately synthetic
test: one controlled car track crosses a line. They demonstrate output format,
not measured traffic accuracy. `synthetic_preview.jpg` is produced from that test.

Replace or supplement these with your own reviewed traffic-video results, and
record the footage source and evaluation in `docs/results.md`.
